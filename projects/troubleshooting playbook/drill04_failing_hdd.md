# Troubleshooting Drill #4 – “Network Slow” (Actually a Failing HDD)  
**Difficulty:** Medium–Spicy  

## Scenario  
User thinks the network is slow; system is freezing.

## Steps Taken  
1. Task Manager → Disk at 100%.  
2. Defender scanning hard.  
3. Event Viewer → disk I/O + bad block errors.  
4. Windows Security → no malware.  
5. Backed up data.  
6. Scheduled hardware replacement.

## Root Cause  
Failing hard drive causing system-wide hangs.

## Lesson Learned  
Not every “network problem” is actually the network.
